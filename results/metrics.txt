EXPERIMENT SETUP
----------------
Task: Monte Carlo π estimation
Goal: Estimate pi using random sampling of points in unit square
Method: pi ≈ 4 * (points_inside_circle / N)

Notebook experiment style:
- Single-run timing per method (no averaging)
- Different N values used per version to demonstrate scaling & bottlenecks

Benchmark size sets used in notebook:
- sizes = [2,000,000, 5,000,000, 10,000,000]
- sizes = [5,000,000, 10,000,000, 20,000,000]

KEY INSIGHTS / BOTTLENECK ANALYSIS
---------------------------------
1) Naive GPU acceleration does not guarantee speed-up:
   - Even with GPU parallel compute, overall runtime is limited by:
     a) CPU-side random number generation
     b) PCIe transfer overhead (host->device)

2) Optimizing kernels alone is insufficient if the pipeline bottleneck is outside GPU compute.

3) Major speed-up achieved only when generating random numbers directly on the GPU:
   - True GPU-side RNG removes CPU RNG bottleneck
   - Eliminates large transfers of random arrays
